Linux support.

## What's new

- **Linux**: new downloads for 64-bit PCs and ARM (like a Raspberry Pi 4/5 with a 64-bit OS). Apple doesn't make Apple Music for Linux, so the app reads what's playing from Linux's standard media controls. It works with Apple Music players like [Cider](https://cider.sh), and with **music.apple.com in a web browser** if you turn on **Include Web Browsers** in the app's menu.
  - Browsers report every site the same way, so the app can't tell an Apple Music tab apart from, say, YouTube. That's why browsers are off unless you turn them on.
  - Finds Discord whether it's installed normally, as a Flatpak or as a Snap.
  - **Open at Login** works on Linux too.
- **FreeBSD**: there's no download, because Electron, which the app is built on, doesn't support FreeBSD officially, and there's no Discord app for FreeBSD. If you have FreeBSD's community Electron and a Discord client that supports Rich Presence, the app runs from source the same way it does on Linux.

## Download

| Computer | File |
| --- | --- |
| Mac (Intel or Apple Silicon) | `AppleMusicRPC-Mac.zip` |
| Windows PC (64-bit) | `AppleMusicRPC-Windows-64bit.zip` |
| Windows on ARM | `AppleMusicRPC-Windows-ARM.zip` |
| Linux PC (64-bit) | `AppleMusicRPC-Linux-64bit.zip` |
| Linux on ARM | `AppleMusicRPC-Linux-ARM.zip` |

**Mac:** unzip, drag **AppleMusicRPC** into **Applications** and open it. macOS will say it can't verify the app: click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**. When asked whether AppleMusicRPC can control Music, click **Allow**.

**Windows:** unzip, open the **AppleMusicRPC** folder and run **AppleMusicRPC.exe**. If SmartScreen warns you, click **More info → Run anyway**.

**Linux:** unzip, open the **AppleMusicRPC** folder and run **AppleMusicRPC**. The app appears in your system tray (on GNOME this needs the AppIndicator extension, which Ubuntu includes). Using Cider? Turn off Cider's own Discord status, or your profile will show both.

Linux support is new. If it doesn't pick up your music, open the app's menu, click **Copy Error Details**, and include that text when you open an issue.
