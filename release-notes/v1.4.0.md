## What's new

- **Update checks**: once a day, the app checks GitHub for a new version. When there is one, an **Update Available** item appears at the top of the menu and opens the download page, and you get one notification about it. Updating is up to you: the app never downloads or installs anything by itself.
- **Check for Updates…** in the menu checks straight away and tells you what it found.
- The menu now shows which version you have.

This is the first version that can tell you about updates, so versions before it won't know about it: download this one once, and you'll hear about the next ones.

## Download

| Computer | File |
| --- | --- |
| Mac (Intel or Apple Silicon) | `AppleMusicRPC-Mac.zip` |
| Windows PC (64-bit) | `AppleMusicRPC-Windows-64bit.zip` |
| Windows on ARM | `AppleMusicRPC-Windows-ARM.zip` |
| Linux PC (64-bit) | `AppleMusicRPC-Linux-64bit.zip` |
| Linux on ARM | `AppleMusicRPC-Linux-ARM.zip` |

**Mac:** unzip, drag **AppleMusicRPC** into **Applications** (replacing the old one if you have it) and open it. macOS will say it can't verify the app: click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**. When asked whether AppleMusicRPC can control Music, click **Allow**.

**Windows:** quit the old version if it's running, unzip, open the **AppleMusicRPC** folder and run **AppleMusicRPC.exe**. If SmartScreen warns you, click **More info → Run anyway**.

**Linux:** quit the old version if it's running, unzip, open the **AppleMusicRPC** folder and run **AppleMusicRPC**.
